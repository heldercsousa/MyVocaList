# Build identity: real MinVer version, build date and monotonic versionCode

Every installed build must state which exact build it is: the app shows the real MinVer version (currently stuck at 1.0.0), the build date, and Android versionCode increases with every build. Gate: Helder approves the spec before any plan or code.
