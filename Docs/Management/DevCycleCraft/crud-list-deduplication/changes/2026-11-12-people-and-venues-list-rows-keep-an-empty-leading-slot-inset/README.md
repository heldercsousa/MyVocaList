# People and Venues list rows keep an empty leading-slot inset

People and Venues rows indent the text as if a leading element were reserved, but nothing fills it. Check in the MD3 lists specs whether an unused leading slot should collapse so the text aligns to the 16dp margin like the other elements, and apply the answer.
