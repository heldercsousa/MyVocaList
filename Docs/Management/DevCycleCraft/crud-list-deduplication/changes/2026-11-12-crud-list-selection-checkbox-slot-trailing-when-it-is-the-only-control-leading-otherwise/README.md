# CRUD list selection checkbox slot: trailing when it is the only control, leading otherwise

Rule to confirm in the MD3 lists docs: checkbox trailing when selection is the row's only control, leading otherwise. Songs puts it trailing beside its YouTube button; Artists puts it leading.

> **Superseded 2026-11-12.** The MD3 lists specs configurations match the rule (no example pairs a checkbox with a trailing action). Each row template places the checkbox in the ListItem leading or trailing slot; the Venues, People, Artists and Songs page tasks apply it.
