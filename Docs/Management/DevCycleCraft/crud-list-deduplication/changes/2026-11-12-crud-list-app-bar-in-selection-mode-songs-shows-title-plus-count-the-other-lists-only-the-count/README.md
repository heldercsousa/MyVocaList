# CRUD list app bar in selection mode: Songs shows title plus count, the other lists only the count

In selection mode, the Songs SmallAppBar shows the page title with 'N selected' as a subtitle, while Venues, People and Artists replace the title with 'N selected'. Pick one MD3-compliant pattern (check the official app bar docs) and apply it to all four lists.
