# Song form: picture at the top, Title and Artist as tap-to-edit text, Artist editable in edit mode

The Song form shows the song picture below Title; a defined Title or Artist shows as larger text and opens for editing when tapped. In edit mode the Artist can change, and a typed artist that does not exist is created.
