# Backfill Deezer images for songs and artists saved before the artwork item

Songs and artists saved before 2026-11-13, or typed without a Deezer pick, have no image. Fetch and store their image URLs from Deezer. Gate: spec first: which records qualify, when it runs, request limits, and a matching rule that avoids wrong pictures.
