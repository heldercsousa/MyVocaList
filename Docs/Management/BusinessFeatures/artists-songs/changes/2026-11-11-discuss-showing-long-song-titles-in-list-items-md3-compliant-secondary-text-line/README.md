# Discuss showing long song titles in list items (MD3-compliant, secondary text line)

Long titles are truncated in the list, so records sharing a prefix look identical. Decide an MD3-compliant way to show more of the title, such as the secondary text line, possibly freed by removing Version and Featured artists. Confirm against the official Material Design 3 list docs.
