- **01/10/2026** - Fix - Optimized DesignSystemPage performance by removing Material Symbols icon button examples. Analysis of debug logs revealed catastrophic performance issues: 4+ second freeze on page load (Davey warnings showing 246x slower than 60fps target), 446+ skipped frames, and repeated MaterialSymbolsOutlined.ttf font loading exceptions. This is a known MAUI/UraniumUI bug (UraniumUI issue #744) where fonts are embedded in APK but library tries to load them as DLL resources, blocking UI thread. Replaced icon buttons with informational card documenting available icon systems. Removed unused MaterialSymbols namespace from XAML. Page now loads smoothly without font exceptions or MaterialButton background warnings
- **01/08/2026** - Fix - Updated UraniumUI.Icons.MaterialSymbols from 2.10.0 to 2.12.1 to match other UraniumUI packages. Restored lightweight Material Symbols comparison with only 2 icon button examples to avoid performance degradation. Updated DesignSystemPage with MaterialOutlined namespace
