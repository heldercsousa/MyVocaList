01. Kits Recomendados para Instalação

Para evitar inflar o contexto do Claude Code com ferramentas redundantes ou inseguras, a adoção deve ser dividida em dois estágios: um Kit Mínimo para operar hoje no .NET MAUI 10 nativo e um Kit Completo que incorpora prototipação, compilação de tokens e auditoria Web caso a camada visual migre para Blazor Hybrid.

Começar Hoje • MAUI 10 Nativo ⚡

Kit Mínimo Operacional

  • 1.
    Microsoft Learn MCP [Verificado]

    Documentação oficial do .NET MAUI 10 (read-only, gratuito, sem autenticação).

  • 2.
    Microsoft.Maui.DevFlow [Preview]

    Árvore visual JSON e screenshots PNG in-app (sólido no iOS/Mac; Android/Win em evolução).

  • 3.
    Maestro MCP / Appium MCP + FlaUI-MCP

    Cobertura caixa-preta em Android/iOS (Maestro/Appium) e árvore UIA3 no Windows (FlaUI-MCP).

  • 4.
    Skill: design-critique (Anthropic)

    Crítica heurística em 5 eixos sobre screenshots + arquivo local DESIGN_CONTEXT.md.

Condicional: Adicione Syncfusion.MAUI.MCP + sfdotnet skills apenas se decidir concluir a suíte comercial.
Expansão & Blazor Hybrid 🚀

Kit Completo de Prototipação e Web

  • 1.
    Google Stitch MCP ou Penpot MCP Oficial

    Geração de variantes noturnas e extração de DESIGN.md (Stitch) ou design open-source self-hosted (Penpot).

  • 2.
    Style Dictionary (via Bash) + Context7 MCP

    Compila tokens JSON únicos para Colors.xaml ou tokens.css; Context7 indexa libs OSS.

  • 3.
    Playwright MCP + Chrome DevTools MCP [Só Web/Blazor]

    Inspeção total de DOM, CSS, console, rede e Lighthouse (40,2k e 58,7k stars).

  • 4.
    AccessLint + Vercel web-design-guidelines [Só Web/Blazor]

    Auditoria automatizada WCAG 2.2 AA (contraste e tamanho de alvo de toque no DOM vivo).

Atenção: Ferramentas de DOM/CSS não enxergam XAML nativo; destravam apenas se adotar Blazor Hybrid.

02. Diagnóstico do Loop Visual por Plataforma

O maior gargalo técnico do .NET MAUI frente à Web em novembro de 2026 é fechar o ciclo autônomo de compilar → capturar tela → inspecionar árvore → validar acessibilidade. Enquanto o ecossistema Web possui cobertura integral, o MAUI nativo exige combinar ferramentas distintas por sistema operacional e compensar manualmente a ausência de auditoria automática de WCAG.

Maturidade do Loop Visual por Alvo de Execução

Pontuação técnica (0 a 5) baseada na disponibilidade de árvore semântica, captura de tela, estabilidade e auditoria WCAG.

Conclusão dos dados: Web/Blazor Hybrid atinge o teto técnico com Playwright e Chrome DevTools. No nativo, iOS/Mac lidera graças ao Microsoft.Maui.DevFlow, seguido pelo Windows via FlaUI-MCP. Android nativo sofre com o status "In progress" do DevFlow e necessidade de ponte manual adb reverse.

✅ O que funciona hoje

Pronto para uso

iOS/Mac: DevFlow lê árvore JSON e muta propriedades em runtime. Windows: FlaUI-MCP (UIA3) captura janelas em background sem roubar foco. Mobile Caixa-Preta: Maestro MCP e Appium MCP navegam pela árvore nativa de acessibilidade.

⚠️ O que é gambiarra (Atrito)

Exige contorno

DevFlow em Android/Win: ainda experimental com issues abertas (#654, #807) e adb reverse manual. Windows-MCP: expõe PowerShell (alerta de segurança) e estoura 25k tokens. iOS WKWebView: exige ponte DevFlow.Blazor para falar CDP.

🚫 O que não existe hoje

Lacuna estrutural

Não existe equivalente ao axe-core / AccessLint para auditar contraste real ou área mínima de toque (dp/pt) em árvore XAML viva, nem hot-swap estilo /impeccable live, nem MCP mantido para o antigo WinAppDriver.

04. Decisão Estratégica: Qual Stack Escolher Agora?

Ter melhores ferramentas de IA em uma stack não significa automaticamente que ela seja a melhor arquitetura para o produto. Como a migração DevExpress → Syncfusion está inconclusa e boa parte da interface será retrabalhada, compare abaixo os três caminhos viáveis para o MyVocaList.

Radar Comparativo das Arquiteturas

Avaliação multidimensional (1 = pior cenário / alto custo, 5 = cenário ideal).

Posicionamento: Autonomia IA vs. Reuso Pós-MVP

Dispersão interativa (Plotly WebGL/Canvas) considerando esforço imediato de migração.

Caminho A • Custo Zero

.NET MAUI 10 Puro

Se o objetivo for lançar o MVP rápido com fluidez nativa e zero licença: aborte a suíte paga da Syncfusion agora. Consolide seus componentes próprios (AppBars, ListItems, FloatingToolbar) e use o Syncfusion.Maui.Toolkit (gratuito/OSS) apenas se precisar de BottomSheet ou Shimmer.

Trade-off: Sem vendor lock-in e scroll nativo imediato, mas sem auditoria WCAG automática no XAML.
Caminho B • Telas Densas Host

MAUI 10 + Syncfusion

Se o objetivo for manter XAML nativo prevendo DataGrids e gráficos complexos no host: conclua a migração e acople imediatamente Syncfusion.MAUI.MCP + sfdotnet skills para impedir que o Claude Code misture APIs legadas ou gere banners de licença.

Trade-off: Suporte Day-1 ao .NET 10, mas exige licença comercial acima do limite Community e customização estética.
Caminho C • Máxima IA & PWA

MAUI Blazor Hybrid

Se o objetivo for maximizar a autonomia visual da IA e reaproveitar a UI no pós-MVP Web/PWA: migre a camada de apresentação para Razor + CSS (com Blazor Blueprint ou MudBlazor) agora, mantendo intactos os serviços C# e a API local.

Trade-off: Destrava Playwright, Chrome DevTools e AccessLint, mas consome ~70 MB extra de RAM no Windows e não usa Native AOT lá.

05. Workflow Ponta a Ponta com Claude Code

Antes da primeira execução, crie o arquivo DESIGN_CONTEXT.md na raiz do projeto fixando as restrições de uso em casa noturna: contraste ≥ 7:1 nos dados da fila, fundo escuro sem branco puro ofuscante, botões de ação ≥ 56 dp no alcance do polegar e separação espacial entre Entrar e Sair da fila.

Diagnóstico

Crítica Rigorosa

Capture screenshots e árvore semântica via DevFlow (iOS/Android), FlaUI-MCP (Windows) ou Chrome DevTools + AccessLint (Blazor). Rode a skill design-critique exigindo teste de leitura em 2 segundos e heurísticas de Nielsen.

Saída: Lista de falhas UX + cores hardcoded

Prototipação

Saída: DESIGN.md + ResourceDictionary/CSS
03
Construção

Implementação Guiada

Em MAUI 10, mantenha Microsoft Learn MCP ativo (e Syncfusion.MAUI.MCP se usar a suíte). Em Blazor Hybrid, acople Context7 MCP e a skill web-design-guidelines da Vercel.

Saída: XAML/Razor livre de APIs legadas
04
Fechamento

Validação Visual

Execute os fluxos de entrar/sair da fila com FlaUI-MCP / Maestro / DevFlow (nativo) ou Playwright + AccessLint (Blazor). Submeta as novas capturas a uma 2ª rodada de design-critique.

Saída: Evidência visual + aprovação WCAG

06. Armadilhas Críticas e Ferramentas Descontinuadas

Antes de configurar o ambiente do Claude Code, observe as mudanças de ecossistema ocorridas nos últimos 12 meses e os riscos operacionais identificados na auditoria técnica.

🪦 Pacotes Descontinuados / Renomeados
  • • @syncfusion/maui-assistant (npm) foi descontinuado; substitua pelo NuGet Syncfusion.MAUI.MCP.
  • • figma-developer-mcp foi renomeado para Framelink MCP (v0.11.0, abr/2026).
  • • Redth.MauiDevFlow foi absorvido por dotnet/maui-labs (Microsoft.Maui.DevFlow).
  • • Galileo AI foi substituído pelo Google Stitch.
🔒 Segurança & Telemetria Local
  • • Windows-MCP: expõe ferramenta PowerShell e recebeu alerta CAUTION (SlowMist); prefira FlaUI-MCP.
  • • Chrome DevTools MCP: envia telemetria e URLs ao CrUX por padrão; passe --no-usage-statistics --no-performance-crux.
  • • DevFlow Agent: expõe servidor HTTP e storage do app; isole estritamente em #if DEBUG.
💳 Cotas, Tokens & Licenças
  • • Figma MCP Oficial: plano gratuito limita a 6 chamadas/mês, travando o agente na 1ª sessão.
  • • Estouro de 25k tokens: dumps completos de árvore UIA/XAML saturam o contexto; filtre profundidade.
  • • Syncfusion MAUI 10: misturar Syncfusion.Maui.* com Toolkit ou divergir versões gera banner de licença.
