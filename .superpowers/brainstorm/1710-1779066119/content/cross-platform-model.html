Cross-Platform Alert — One Interaction Model, Two Expressions

IxD principle: design the user's mental model once. Let each platform express it natively. The admin experiences the same rhythm on both OSes.

The universal interaction model (platform-agnostic)

Song starts
Admin launches YouTube URL. Timer begins based on DurationSeconds.
~45s remaining — Stage 1 alert
Admin sees: next singer name + song
Next singer sees/hears nothing yet — this is for the admin only.
~15s remaining — Stage 2 alert
Stronger signal — admin cues the next singer to approach the mic.
Haptic on both platforms.
Song ends — admin marks done
Admin taps "Done" (from notification, overlay, or app). Queue advances. Next singer confirmed.

What the admin experiences — identical on both

Same timing

Same content

Android
Blinking overlay over YouTube

Notification banner over YouTube

Nielsen heuristic #4 — Consistency and standards: the admin's mental model is identical. The visual channel differs, but timing, content, and action are the same.
