YouTube Data API v3 — one decision needed

In-app search requires a YouTube Data API v3 key (free quota: 10,000 units/day — a search costs 100 units → 100 searches/day free).
Alternative: admin pastes the URL manually — zero API dependency, works forever.
Recommended: support both. Paste works always; search is a convenience enhancement that requires the admin to provide their own API key in Settings.
